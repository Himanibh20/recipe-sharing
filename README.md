# 🍽️ Recipe Sharing Web Application

## 📌 Project Overview

The Recipe Sharing Web Application is a simple and interactive web-based platform that allows users to create, store, and share their favorite recipes. Users can add recipe details such as title, description, and cooking instructions, which are saved locally in the browser using LocalStorage.

This project demonstrates frontend development skills using HTML, CSS, and JavaScript while implementing client-side data persistence and browser sharing functionality.

---

## 🚀 Features

* ➕ Add new recipes with title, description, and instructions
* 📖 View all saved recipes instantly
* 💾 Store recipes using LocalStorage for persistent data
* 📤 Share recipes using the browser's Web Share API
* 📱 Responsive design for desktop and mobile devices
* ⚡ Fast and lightweight application with no backend required

---

## 🛠️ Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling, layout, and responsiveness
* **JavaScript (ES6)** – Application functionality and DOM manipulation
* **LocalStorage API** – Client-side data storage
* **Web Share API** – Native recipe sharing support
